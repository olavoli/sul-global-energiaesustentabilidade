# Cobertura editorial

`bun run newsroom:coverage` agrega temas, países, regiões, idiomas, tipos, confiança e instituições. Sinaliza concentração no Brasil, Norte Global, empresas, uma instituição ou tema, e ausência de América Latina, África, Ásia e fontes primárias.

Alertas não são metas rígidas nem mudam confiança. Com catálogo vazio, o comando declara ausência de base empírica. Métricas por fonte são diagnóstico técnico/editorial, nunca autorização de publicação.
