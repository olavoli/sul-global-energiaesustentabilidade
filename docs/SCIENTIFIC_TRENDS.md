# Tendências Científicas

A Sprint 26 transforma somente a Memória Temporal em sinais observacionais determinísticos. Não consulta APIs, prevê, extrapola, usa IA ou cria conteúdo. `insufficient-data` é o resultado obrigatório quando a política mínima não é atendida.

O pipeline privado executa elegibilidade, métricas, cobertura, confiança e warnings. Candidatos são sinais preliminares com warning obrigatório, nunca tendências consolidadas. Comandos `science:trend:*` são dry-run por padrão; persistência local exige `--apply`, ator e autorização posterior. Staging e produção são bloqueados.
